# Schema responsibility index

Implemented internal v1 skeleton schemas: probe request/result, environment template envelope and local artifact evidence manifest. They are closed Draft 2020-12 shapes, tested with positive and negative fixtures, explicit formats and offline reference denial. The actual health API uses the vendored official OpenAPI metaschema. No public contract has been published.
