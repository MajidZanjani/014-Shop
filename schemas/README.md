# Schema responsibility index

Implemented internal v1 skeleton schemas: probe request/result, environment template envelope and local artifact evidence manifest. They are closed Draft 2020-12 shapes, tested with positive and negative fixtures, explicit formats and offline reference denial. The actual health API uses the vendored official OpenAPI metaschema. No public contract has been published.

| Later family — unimplemented | Owner |
|---|---|
| Product/profile/vendor/family/term/band, offer/legal/catalog revision and conformance schemas | T03, CAT-01–05 |
| Contact/configuration/host/quote/order/acceptance/money/licence/support/evidence records and durable snapshots | T05, DATA-01–04 |
| Payment intent/callback/reconciliation/uncertainty/capture/refund protocols | T08, PAY-01–05 |
| Selected-bank wire messages and authenticated observations | T09, BANK requirements |

The responsibility index is not validation of those later families. No permissive placeholder schema, competing catalog, product rate/right/approval or support/payment capability is created. Product authority remains the exact embedded product source.
