# Pitfalls and phase controls

Source: October 20 proposal/handoff. These are anticipated risks, not observed implementation defects.

| Risk / warning sign | Prevention and proof | Phase |
|---|---|---|
| Old trial profiles, domains or decisions survive reset | Source hash/inventory check, exact new IDs and route review | T01/T13 |
| Labels imply unique billable Cyclone coverage | Keep all labels; approval-backed nonoverlapping coverage | T03 |
| Null or unknown recurrence becomes zero/free | Exact money components and approval-gated totals | T03/T07 |
| Quantity clones IP rights or support silently | One IP scope/line, explicit support quantity, no implicit merging | T07 |
| Shared email domain reveals host records or balances | Verified resource membership, protected editor, MFA everywhere privileged | T06 |
| Timeout retries charge twice | preparing/uncertain distinction, one dispatch, real order locks and fault bank | T08/T09 |
| Restore forgets completed work/keys/numbers | Retain prepared/completed evidence, reconcile original identities and hold ambiguity | T10/T12 |
| Restored credentials regain revoked access | Invalidate sessions/challenges and reconcile grants/MFA codes before access | T12 |
| Support retries double-debit or restore spent hours | Durable credit/task/reservation identities, archived completion and ledger statements | T10/T12 |
| New release breaks old island chunks | Content-addressed/release assets survive cache lifetime and rollback | T11/T13 |
| AWS assumptions copied to OVH or DNS credentials added unnecessarily | Actual ACL/Object Lock proof, standard ACME first, conditional scoped DNS-01 | T11/T12 |
| Source cost/version assertions treated as account proof | Exact patches/quote/capability/qualification evidence at relevant task | T02/T09/T11/T14 |
