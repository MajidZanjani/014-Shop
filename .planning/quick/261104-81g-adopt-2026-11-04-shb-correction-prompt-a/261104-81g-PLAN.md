The amendment identifies the previous session's `"no local work remains"`
stance as an unsupported stopping condition and names concrete defects:

1. **SHB-13 silent-skip** — `backend/shop/shb/tests.py` lines 251–300 imports
   `DiscountReservation` from `shop.payments.models` (wrong module; actual
   is `shop.shb.models`), catches the `ImportError`, and wraps the
   SHB-13-mandated assertion in `if DiscountReservation is not None:`. The
   assertion is silently skipped.
2. **SHB suite definition asymmetry** — `scripts/check_shb.py:49` omits
   `shop.shb.discount_issuance_tests`; `scripts/check_shb_retained.py:164`
   includes it. The two "SHB suite" definitions disagree.
3. **CI exercises legacy, not SHB** — `scripts/check_backend.py:127`
   core-local module list contains dozens of `shop.catalog.*`, `shop.worker.*`,
   `shop.payments.*` modules and zero `shop.shb.*` modules. Line 147
   asserts `/api/v1/catalog/` returns 200, which contradicts
   invitation-only behavior. `.github/workflows/ci.yml` requires
   `scripts/check.py all`, which routes through this check_backend lane.
4. **Development workflow runs IP rehearsal** — `.github/workflows/development.yml:91`
   invokes `scripts/demo_purchase_flow.py`, which creates old IP sales,
   licence entitlements, reference-design deliveries and support credits.
5. **REQUIREMENTS.md cites nonexistent methods** — rows for SHB-07, 19,
   20, 21, 22, 23, 24, 26 name `test_shb_NN_*` methods that do not exist
   in the source. The committed tests for those SHBs live under their
   original method names in `backend/shop/shb/paid_order_tests.py`. Only
   18 `def test_shb_` methods actually exist; the complete-explicit-coverage
   document names ~26.

The reconciliation below does not edit code, suites, CI or test files.
