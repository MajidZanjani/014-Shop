# Protected local quotation-request capture

Owner-only GET/POST `/api/v1/quotation-requests/` and GET `/api/v1/quotation-requests/<uuid>/` capture an exact retained cart snapshot. New requests require the current nonempty valid snapshot and catalogue revision. Submission shares the cart-save row lock. One request per snapshot; retries and separate keys/tabs reconcile to that request. Retained retry-key aliases reject changed reuse. Later edits/catalogue changes cannot change or prevent retrieval/replay of the captured snapshot. APIs expose no update/delete operation. This is immutable-by-API request capture, not a commercially approved quote.

The existing React cart island now submits all saved lines, reviews captured line identities/configuration/quantities, lists the newest 20 requests and retrieves exact captured details. Prices/rights stay null; acceptance/checkout disabled. Uncertain responses retain the same in-memory payload and block cart mutations until retry resolves. No browser persistence. Reload loses the in-memory retry payload; server snapshot uniqueness still prevents duplicate capture on resubmission. No mail, staff workflow, order, payment, document issue, support credit, private hosts or external effects.
