## Critical Anti-Patterns (retained + added)

| Pattern | Description | Severity | Prevention |
|---|---|---|---|
| Treat silently-skipped assertion as coverage | SHB-13's `if X is not None:` guard combined with an always-failing import caused the mandated assertion to never run; the test still passed and was counted as SHB-13 coverage | blocking | Grep every SHB test module for `try: from ... import ... except ... = None` followed by `if ... is not None:`; either use the correct import unconditionally or justify the guard in the docstring with the exact scenario it protects |
| Cite a test method by a name grep cannot find | REQUIREMENTS.md and shb-complete-explicit-coverage-2026-11-03.md cite `test_shb_07/19/20/21/22/23/24/26_*` that do not exist; the real tests live under their earlier names in paid_order_tests.py | advisory | Before adding a traceability row, confirm the method name with `grep -Rn "def <name>" backend/` |
| Anonymous-catalog HTTP 200 in CI | `check_backend.py:147` asserts `/api/v1/catalog/` returns 200; contradicts invitation-only SHB behavior | advisory | Remove or re-scope to an invitation-authenticated fixture; preserve the 404/403 semantics for anonymous |
| Legacy IP demo in mandatory development CI | `.github/workflows/development.yml:91` requires `demo_purchase_flow.py` which creates old IP sales; this is historical regression, not SHB acceptance | advisory | Mandatory CI runs an SHB-scoped demo; legacy demo retained as a separate lane |
| 14-phase progress framing | Reporting `percent: 7` (phases) as headline progress misrepresents SHB-completion state | advisory | Lead with SHB-NN coverage, test counts and external gates; only cite phase counts as a historical denominator |
