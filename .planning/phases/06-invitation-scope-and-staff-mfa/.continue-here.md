## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Editing shared-lane source files during a running shared regression | scripts/check_shb_retained.py's save_record enforces that the sources hashed before the run match those at commit; mid-run edits raise `source changed during retained verification` and the run is wasted | advisory | Commit tooling edits BEFORE launching the shared lane. If a label list change is needed, land it in a separate commit, then rerun. |
| Treating SCOPE_FIELDS as a 1:1 column list on the published row | DiscountIssuanceScope's claim_period_days drives expires_at computation but is NOT a column on DiscountCode. A naive `copy_fields` loop would set a non-existent attribute. | advisory | Keep the derived field explicit in `prospective(event)` and omit it from the straight-copy comparison. |
| Letting the publication-matches trigger reject every DiscountCode insert | The AFTER INSERT deferred trigger must only check rows where a DiscountIssue exists with the same id; otherwise it rejects fixture-issued codes created by `discounts.issue_fixture`. | advisory | Use an EXISTS-JOIN gate on DiscountIssue id = DiscountCode id in the trigger body. |
