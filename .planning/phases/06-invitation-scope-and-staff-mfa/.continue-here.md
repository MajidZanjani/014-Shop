## Critical Anti-Patterns (retained + added)

| Pattern | Description | Severity | Prevention |
|---|---|---|---|
| Treat silently-skipped assertion as coverage | SHB-13's `if X is not None:` guard combined with an always-failing import caused the mandated assertion to never run; the test still passed and was counted as SHB-13 coverage | blocking | Grep every SHB test module for `try: from ... import ... except ... = None` followed by `if ... is not None:`; either use the correct import unconditionally or justify the guard in the docstring with the exact scenario it protects |
